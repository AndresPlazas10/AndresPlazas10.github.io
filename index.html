Sobre mí

Soy Andrés Felipe Plazas Mendivelso, estudiante de Ingeniería de Sistemas y desarrollador Full Stack Jr. Construyo productos web que resuelven operaciones reales en negocios de alimentos y retail, combinando experiencia de usuario clara con backend sólido.

Propuesta de valor

Convierto necesidades operativas en funcionalidades medibles: control de inventario, flujo de ventas, autenticación segura y reportes útiles para decisión.

Enfoque técnico

React para interfaz modular, Supabase para backend as a service y PostgreSQL como base transaccional. Priorizo diseño escalable, componentes reutilizables y mantenimiento simple.

Calidad y rendimiento

Implemento validaciones de entrada, consultas optimizadas, carga diferida de scripts, semántica accesible y prácticas de versionado orientadas a equipos.

Stocky: caso técnico destacado

Stocky nace para resolver un problema común en negocios pequeños y medianos: pérdidas por control manual de inventario, poca trazabilidad de ventas y reportes tardíos para tomar decisiones.

Stack y arquitectura

Frontend en React, backend y auth con Supabase, y datos en PostgreSQL. Separación por módulos para ventas, productos, empleados y reportes.

Retos técnicos resueltos

Sincronización de stock tras ventas, validación de transacciones, control de estados de interfaz y manejo robusto de errores para escenarios de red inestable.

Decisiones clave

Modelo de datos orientado a consistencia, componentes reutilizables, políticas de acceso por rol y flujos desacoplados para facilitar nuevas funcionalidades.

Rendimiento y buenas prácticas

Consultas optimizadas, reducción de renderizados innecesarios, carga diferida en vistas secundarias y estructura preparada para CI/CD y monitoreo.

Diferenciador frente a otros POS

Enfoque específico para negocios gastronómicos, simple de usar para operación diaria y diseñado para evolucionar sin rehacer la base técnica.
