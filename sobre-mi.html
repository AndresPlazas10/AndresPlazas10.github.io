Sobre mí

Soy Andrés Felipe Plazas Mendivelso, estudiante de Ingeniería de Sistemas y desarrollador Full Stack Jr. Convierto necesidades operativas en funcionalidades medibles: inventario, ventas, autenticación segura y reportes para la decisión.

Propuesta

Productos web y móviles con experiencia de usuario clara y backend sólido para cafeterías, restaurantes y retail que dependen de datos confiables cada día.

Enfoque técnico

React y React Native para interfaces web y móviles, Supabase para backend as a service y PostgreSQL como base transaccional. Separación por dominios de negocio.

Calidad

Validaciones de entrada, consultas optimizadas, carga diferida, semántica accesible y flujos de trabajo orientados a equipos.
